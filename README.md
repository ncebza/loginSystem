QuickChat Part 2

Overview

QuickChat is a Java messaging application developed as part of the PROG5121 Portfolio of Evidence. It allows users to log in, create messages, and choose whether to send, store, or disregard them.

Features

- User login and registration
- Send messages to recipients
- Validate recipient cell phone numbers
- Check that messages do not exceed 250 characters
- Generate a unique message ID for each message
- Create a message hash
- Send, store, or disregard messages
- Save stored messages in a JSON file
- Display message details and the total number of sent messages

Technologies Used

- Java
- Apache NetBeans
- Maven
- JUnit 5

How to Run

1. Open the project in Apache NetBeans.
2. Build the project.
3. Run "LoginSystem_Nceba_Part1.java".
4. Register or log in using your details.
5. Follow the menu instructions to use QuickChat.

Testing

JUnit tests are included to test message validation, message IDs, message hashes, message options, and the QuickChat menu.
